# Kalima Kerala Kitchen Hotel - Official Website

A blazing-fast, lightweight, zero-dependency, and mobile-first website for **Kalima Kerala Kitchen Hotel** located in Thousand Lights, Chennai.

---

## 🚀 Key Features

1. **Lightweight & Concurrency-Ready**: Pure HTML5 + Modern CSS + ES6 Vanilla JS modules. Zero heavy framework lag, sub-second load times worldwide.
2. **Dynamic Data Layer**:
   - `assets/js/data/restaurantData.js`: Central store for contact, address, timings, and map links.
   - `assets/js/data/menuData.js`: Menu categories, dishes, prices, dietary tags, and images.
   - `assets/js/data/testimonialsData.js`: Customer reviews and ratings.
3. **Interactive Menu Explorer**: Instant real-time search, category tabs (Biryani, Porotta, Seafood, Sadya, Curries, Snacks), dietary pills, and direct "Order on WhatsApp" buttons for each dish.
4. **Instant WhatsApp Integration**: Pre-fills dish details or table reservations and routes directly to `+91 9894080389`.
5. **Google Maps Embed & Directions**: One-tap direct directions to `37, Aziz Mulk 1st St, Thousand Lights West`.

## 🌐 How to Deploy to GitHub Pages (1-Click)

1. Push this entire project folder to your GitHub repository (e.g. `main` branch).
2. Go to your GitHub repository -> **Settings** -> **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Your site is live immediately at `https://<your-username>.github.io/<repository-name>/` with **0 CORS errors**!

---
## ⚡ How to Deploy to Vercel (1-Click)

1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **Add New Project** and select your GitHub repository.
3. Framework Preset: **Other** (or Vite).
4. Root Directory: `./`
5. Click **Deploy**.
6. Your website is live worldwide with full SSL and global CDN caching.

---

## 📸 Updating Images & Menu Dishes in the Future

- **To add/replace dish photos:** Place your image file in `assets/images/` and update the `image:` property in `assets/js/data/menuData.js`.
- **To change prices or items:** Edit `assets/js/data/menuData.js` directly.
- **To change address or phone number:** Edit `assets/js/data/restaurantData.js`.
